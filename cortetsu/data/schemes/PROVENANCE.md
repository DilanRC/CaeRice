# Cortetsu scheme data

This directory is the Cortetsu-owned source for the generated scheme pack and
the preserved local scheme inventory. The data was materialized during the
Zero-Caelestia migration from the repository's former legacy staging tree.

The original upstream attribution and migration snapshot remain under
`docs/history/caelestia/`. Runtime and scheme generation read only this
directory; no external checkout or installed shell package is required.
