# Cortetsu base runtime provenance

This directory is the vendored source baseline used by the Cortetsu runtime
builder. It was materialized from the exact `v2.4.0` source revision
`24aa15eefdb146350d2548c0a015b04eddbd1008` during the Zero-Caelestia source
ownership migration.

The files are being migrated into Cortetsu-owned modules. Until each file is
replaced, its original upstream license and attribution remain part of the
source tree. The build must copy this directory only from the repository and
must not fetch or use an external checkout.
